---

## ✨ Overview

This portfolio is more than a static resume — it is a bold digital identity designed for developers and creators. It blends clean UI, smooth motion, 3D visuals, and responsive layouts to deliver an immersive browsing experience.

From the cinematic landing section to animated project cards and contact form integration, the site is built to feel premium, modern, and memorable.

---

## 🌟 Highlights

- 3D animated landing experience using Three.js and React Three Fiber
- Smooth motion design powered by Framer Motion
- Responsive and mobile-friendly layout
- Projects section with card-based storytelling
- Skills and technologies showcase
- Contact form with EmailJS integration
- Modern dark aesthetic with immersive backgrounds and glow effects
- Optimized for performance and clean developer experience

---

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org/) — App framework
- [React](https://react.dev/) — UI library
- [Tailwind CSS](https://tailwindcss.com/) — Styling system
- [Framer Motion](https://www.framer.com/motion/) — Motion and transitions
- [Three.js](https://threejs.org/) — 3D rendering
- [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) — React renderer for Three.js
- [@react-three/drei](https://github.com/pmndrs/drei) — Helpful 3D helpers and components
- [EmailJS](https://www.emailjs.com/) — Contact form email delivery
- [Sonner](https://sonner.emilkowal.ski/) — Toast notifications
- [Swiper](https://swiperjs.com/) — Touch-friendly slider components
- [Lucide React](https://lucide.dev/) — Modern icon pack

## 🚀 Getting Started

### 1) Clone the repository

```bash
git clone https://github.com/GURUPRASAD178/NextJs_Portfolio.git
cd NextJs_Portfolio
```

### 2) Install dependencies

```bash
npm install
```

### 3) Run locally

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the app.

### 4) Build for production

```bash
npm run build
npm run start
```
